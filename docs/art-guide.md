## 2. 복선 심기

- **티 별로 안 나게.** 처음 볼 때는 배경, 다시 볼 때 걸리는 정도.
- **악몽 안에 13호 악몽을 직접 등장시키지 않는다.**
- 대신 **다른 손님의 탐색맵에 "내" 단서를 섞는다.**
  - 소품 / 낙서 / 사진 / 반복되는 오브젝트 형태로.
