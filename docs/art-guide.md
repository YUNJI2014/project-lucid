## 1. 프롬프트 일관성

- 스타일 키워드를 **고정 블록**으로 만들어 두고 모든 프롬프트 앞에 그대로 붙인다.
- 현실(2D)과 악몽(3D)은 **의도적으로 다른 룩**이지만, 각 레이어 내부에서는 일관돼야 한다.
- 채택한 프롬프트는 결과물과 함께 로그에 기록한다. **기억에 의존하지 말 것.**

### 레이어별 방향 (기획서 9장)

| | 현실 — 2D 도트 | 악몽 — 3D |
|---|---|---|
| 색감 | 따뜻한 색감 | 불안정한 조명 |
| 공간 | 정돈된 공간 | 과장된 공간감, 왜곡된 환경 |
| 사물 | 평범한 크기 | 비정상적인 크기 |
| 카메라 | 안정적 | 불쾌한 거리감과 원근 |
| 인상 | 편안한 생활 게임 | 현실보다 더 생생하고 입체적 |

> 목표는 **"악몽 쪽이 더 진짜 같다"** 는 감각. 이건 연출 취향이 아니라 후반 복선이다.

## 2. 복선 심기

### 규칙

- **티 별로 안 나게.** 처음 볼 때는 배경 오브젝트, 다시 볼 때 걸리는 정도.
- **금지 — 다른 손님의 악몽에 13호실이나 플레이어 본인을 직접 등장시키지 않는다.**
- 대신 특성 손님의 3D 탐색맵에 플레이어 관련 단서를 **아주 조금씩** 섞는다.

### 단서 후보 (기획서 12장)

- 손님과 아무 관련 없어 보이는 오래된 커플 사진
- 누군가에게 반복해서 미안하다고 적힌 메모
- 한쪽만 남은 커플링
- 이전 여관 주인의 치료 기록 일부
- 플레이어가 처음 보는 물건인데 자동으로 이름을 알고 있음
- 다른 환자 기록 사이에 이름이 지워진 치료 기록
- 플레이어가 특정 장소를 보고 "익숙하다"고 혼잣말함

### 심은 단서 배치표

한 맵에 몰리거나 눈에 띄는 정도가 튀지 않게, **여기서 전체를 보고 배분한다.**

| 맵 | 단서 | 가리키는 것 | 눈에 띄는 정도 (1~5) | 배치 완료 |
|---|---|---|---|---|
| 치매 | | | | |
| 퇴역 기사 | | | | |
| PTSD | | | | |

> 눈에 띄는 정도 기준 — 1: 스쳐 지나감 / 3: 상호작용하면 보임 / 5: 대사나 연출로 시선을 끔
> 5는 게임 전체에서 최소한으로.

## 3. 저작권

- 기존 캐릭터를 직접 참조한 몹은 **실루엣·색·특징을 바꿔 리디자인**한 뒤 확정한다.
- 생성형으로 뽑은 결과물이 특정 작품과 지나치게 닮았는지 확정 전에 확인.
