# 《13호의 여관》 핵심 플레이 구조 (v2)

> 이 문서는 기존 [GDD.md](GDD.md) 4~9장(일반/특성 손님 구분, 3D 1인칭 탐색, 실시간 전투)을
> 대체하는 갱신본이다. 손님 구분 없이 **하나의 통일된 루프**로 재구성했다.
> ⚠️ GDD.md/README.md는 아직 구버전 내용(3D 탐색·실시간 전투)을 그대로 담고 있다 — 동기화 필요.

---

## 전체 루프 요약

```
손님 체크인
→ 객실 청소
→ 제한된 횟수로 단서 탐색
→ 밤에 악몽 진입
→ 단서를 이용한 턴제 전투
→ 기억 삭제 또는 정화
→ 안식/용기 파편 획득
→ 스킬 장착
→ 다음 손님
```

호텔 파트가 별도 경영 게임으로 튀지 않으면서도, 전투에 필요한 정보를 직접 획득하는
플레이 공간이 되는 것이 이 구조의 핵심.

---

## 낮 — 여관 관리 및 단서 탐색

**기본 흐름**

```
손님 체크인 → 객실 배정 → 청소 → 제한된 횟수만큼 단서 조사
```

- 청소 자체는 복잡한 미니게임이 아니라, 객실을 탐색하게 만드는 **명분**에 가깝다.
- 방 안의 특정 오브젝트에 접근하거나 마우스를 올리면 `?` 표시가 뜬다.
- 상호작용 가능한 오브젝트는 방마다 **10~12개**, 조사 가능 횟수는 **4회** 정도로 구성한다 (기준값, 손님별로 조정 가능).
- 모든 물건을 조사할 수 없으므로, 플레이어는 제한된 횟수 안에서 **어떤 물건이 중요한 단서인지 판단**해야 한다.

**예시 — 퇴역기사의 객실**

- 낡은 군번줄
- 오래된 전쟁 사진
- 접혀 있는 편지
- 검 손질 도구
- 깨진 술병

### 단서의 역할

획득한 단서는 단순 수집품이 아니라 **밤의 전투에 직접 사용**된다.

| 기능 | 내용 |
|---|---|
| 적의 공격 패턴 공개 | 낮에 특정 단서를 찾으면 밤에 적이 쓰는 기술·조건을 미리 알 수 있다 |
| 증거물 제시 | 전투 중 발견한 물건을 상대에게 보여줄 수 있다. 적절한 증거물 제시 시 상대가 기억에 동요해 스턴되거나 특정 패턴이 중단된다 |
| 정화 조건 해금 | 핵심 단서를 충분히 확보하면 기억을 삭제하지 않고 **정화**하는 방법을 쓸 수 있다 |

탐색을 잘할수록 밤의 전투에서 선택지가 많아진다.

## 밤 — 손님의 악몽 진입

밤이 되면 플레이어는 해당 손님의 꿈속으로 들어간다.
전투는 기존에 정했던 **2D 턴제 전투**를 사용한다.
플레이어는 낮에 획득한 단서를 기반으로 적의 트라우마를 공략한다.

**기본 행동**

- 공격
- 방어
- 스킬
- 증거 제시
- 기억 삭제
- 정화

### 기억 삭제

- 손님의 트라우마 기억 자체를 삭제한다.
- 기억이 삭제되면 해당 기억과 연결된 적의 공격 패턴이 전투에서 제거된다 — 가장 직접적이고 강력한 공략법.
- 성공 시 **안식 파편** 획득.

### 정화

- 기억을 삭제하지 않고 손님이 그 기억을 받아들이게 만드는 방식.
- 낮 동안 적절한 단서를 확보해야 사용 가능.
- 전투 중 증거물 제시, 특정 패턴 버텨내기 등 조건을 만족시켜 정화 가능 상태를 만들어야 한다.
- 성공 시 **용기 파편** 획득.

---

## 파편과 스킬

| 파편 | 획득 경로 | 성향 |
|---|---|---|
| 안식 파편 | 기억 삭제 성공 | 강한 공격, 패턴 제거 등 강력한 효과 중심 |
| 용기 파편 | 정화 성공 | 보호·회복·정보 확보·상태 이상 해제 등 안정적 효과 중심 |

- 파편은 플레이어의 스킬이 된다. 단, 제한된 **스킬 슬롯**에 원하는 파편만 장착 가능.
- 빌드 예시: `안식/안식/용기/용기` (혼합형), `안식/안식/안식/안식` (공격 중심형)
- 이 선택은 **최종 엔딩에도 영향**을 준다.

## 손님별 전투 기믹

방향은 기존과 동일하게 유지한다.

**기억 소실을 겪는 손님**
- 기억을 갉아먹는 존재가 등장
- 전투 정보나 행동 일부가 사라짐
- 낮에 발견한 단서가 잃어버린 정보를 보완

**퇴역기사**
- 죽은 전우들의 환청이 공격으로 구현 — 비난의 말 자체가 피해를 줌
- 군번줄, 전우의 편지 등으로 상대를 동요시키거나 정화 가능

**PTSD 손님**
- 특정 소리나 사물이 트리거가 됨 → 트리거 발생 후 강력한 패턴 사용
- 낮에 트리거를 파악했다면 밤에 공격을 예측·대응 가능

**최종전**
- 기존 설정대로 플레이어 자신의 트라우마 자아와 싸운다.
