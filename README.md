# Remorial *(가제)*

> `remember` + `memorial` — 기억하는 것과 기리는 것.

> 고통을 지워 안식을 얻을 것인가, 아니면 기억한 채 살아갈 용기를 가질 것인가?

**3D 스토리 어드벤처 + 탐색/기믹 + 실시간 액션 전투** — Unity 1인용 게임.

| | |
|---|---|
| 플레이 인원 | 1인 |
| 개발 인원 | 4인 |
| 진행 기간 | 게임 내 7일 |
| **데모 구현 범위** | **DAY 1 ~ DAY 3** |
| 데모 목표 플레이타임 | 약 20분 내외 |
| 그래픽 | 전체 **3D** |
| 시점 | **1인칭** |
| Unity 버전 | **6000.3.23f1 (Unity 6.3 LTS)** |
| 리포지토리명 | `project-lucid` (초기 가제 — 게임명이 바뀌어도 저장소 슬러그는 그대로 둔다) |

## 무슨 게임인가

플레이어는 7일 동안 여관에 찾아오는 **몽식증**(감정이 악몽으로 구체화되는 증상) 손님들을 치료하는 **여관 주인**이다.
손님이 방에 들어가면 평범했던 객실은 손님의 기억과 트라우마에 영향을 받아 **3D 악몽 영역**으로 변화한다.

플레이어는 그 영역을 탐색하며 손님의 과거를 파악하고, **그 영역에서 작동하는 기믹과 보스의 약점에 관한 단서**를 발견한다.
영역의 끝에서 손님과 대면해 **3D 실시간 액션 전투**를 치른다.

**보스를 해결하는 방법은 두 가지이고, 별도의 선택창이 아니라 플레이 방식 자체가 결과를 가른다.**

| 방법 | 결과 | 보상 |
|---|---|---|
| 기본 공격과 파편 스킬로 **직접 쓰러뜨린다** (보스 HP 0) | 트라우마 기억 삭제 | **안식 파편** |
| 악몽 영역의 **필드 기믹 조건을 전부 해결**해 무력화한다 | 기억을 지우지 않고 받아들임 | **용기 파편** |

파편은 이후 전투 스킬이 되어, 제한된 슬롯에 장착해 전투 빌드를 구성한다.

---

## 핵심 루프

```
손님 등장 → 객실 입실 → 악몽 영역 생성 → 영역 탐색
→ 스토리 / 기믹 / 보스 약점 단서 발견
→ 보스 대면 → 실시간 전투
       ├─ 직접 전투 : 기본 공격 + 파편 스킬 → 보스 HP 0 → 안식 파편
       └─ 필드 공략 : 필수 기믹 전부 해결 → 보스 무력화 → 용기 파편
→ 획득 파편 장착 → 다음 DAY
```

DAY 1~6에는 손님을 한 명씩 해결하고, DAY 7에는 새로운 손님 없이 주인공의 최종 영역을 다룬다.

## 단서

단서는 **전투에서 쓰는 아이템이 아니라 악몽을 이해하기 위한 정보**다. 세 가지 역할이 있다.

1. **스토리 파악** — 손님에게 무슨 일이 있었는지
2. **기믹 파악** — 필드에서 무엇을 해야 하는지 (정답을 알려주지 않고 규칙을 추론하게 한다)
3. **보스전 길라잡이** — 보스가 언제 약점을 드러내는지

> **단서는 보스를 약하게 만들지 않는다. 원래 있던 약점을 알려줄 뿐이다.**
> 그래서 단서를 놓쳐도 전투는 가능하다. 직접 관찰하고 시행착오를 겪어야 해서 난도만 올라간다.

---

## 전투와 파편

전투 중 기본 행동은 **이동 / 기본 공격 / 파편 스킬 / 회피 / 필드 오브젝트 상호작용**이다.
게임 시작 시 초기 파편 4종(절단·정지·숨 고르기·붙들기)이 주어진다.

| | 획득 조건 | 성향 |
|---|---|---|
| **안식 파편** | 보스를 직접 쓰러뜨림 | 높은 피해량, 강제 경직, 범위 공격, 방어 무시, 순간 무적 — **문제를 직접 제거하는 힘** |
| **용기 파편** | 필드 기믹 전부 해결 | 체력 회복, 보호막, 상태이상 해제, 회피 강화, 공격 예고 — **그 안에서 살아남는 힘** |

안식이 단순히 "나쁜 선택"으로 보이지 않도록, 안식 스킬은 실제 플레이에서도 매력적이게 설계한다.

> **DAY 7에서는 획득한 파편이 전부 봉인되고 초기 4종만 쓸 수 있다.** 이때 스킬 설명이 3인칭에서 1인칭으로 바뀐다.

## DAY 별 플레이 다양성

공통 구조는 같지만(탐색 → 단서 → 보스 → 안식/용기 → 파편), 정보를 얻고 기믹을 푸는 방법은 반복하지 않는다.

| DAY | 단서의 중심 | 용기 기믹 |
|---|---|---|
| DAY 1 | 문장·기록 비교 | 비난 공격을 이용해 왜곡 오브젝트 파괴 |
| DAY 2 | 환경 흔적·탈출 경로 | 수위에 맞춰 배수 장치 순차 작동 |
| DAY 3 | 소리·통화 순서 | 실제 통화를 정확한 순서로 연결 |
| DAY 4 | 공간 변화 기억 | 변화된 공간의 기억 고정 |
| DAY 5 | 시선의 발생 원인 | 무대 장치로 시선 분산 |
| DAY 6 | 두 세계의 대응 관계 | 양쪽 세계의 기억 연결 |
| DAY 7 | 플레이어 자신의 기억 | 자신의 과거 복원 |

## 7일 구성

| 구분 | Day | 손님 | 구현 |
|---|---|---|---|
| 간단 손님 (튜토리얼) | DAY 1 | 잔소리 공포 | **데모** |
| | DAY 2 | 물 공포 | **데모** |
| | DAY 3 | PTSD | **데모** |
| 핵심 손님 (기믹 심화) | DAY 4 | 기억 소실병 | 정식 버전 |
| | DAY 5 | 시선 공포증 | 정식 버전 |
| | DAY 6 | 이중인격 | 정식 버전 |
| 최종 | DAY 7 | 주인공 자신 | 정식 버전 |

**데모는 DAY 1~3 까지다.** DAY 3 종료 후 **닫힌 방** 앞에서 짧은 중간 엔딩과 **TO BE CONTINUED** 로 끝난다.

정식 버전에서는 마지막 날 그 방에서 **자기 자신의 트라우마**와 마주하며, 선택에 따라 망각/노멀/용기 세 엔딩으로 갈린다.

## 차별점

1. 손님의 객실이 트라우마를 기반으로 한 3D 악몽 영역으로 변화
2. 단서가 수집품이 아니라 **스토리·필드 기믹·보스 약점을 이해하는 정보**로 기능
3. **DAY 마다 단서를 얻고 해석하는 방식이 다름** (문장 비교 → 환경 관찰 → 소리·순서)
4. **같은 보스에게 두 가지 공략 방식이 존재** — 직접 전투(안식) / 필드 기믹 완수(용기)
5. 별도의 선택창이 아니라 **실제 플레이 방식이 분기를 결정**
6. 획득한 파편이 다음 전투의 스킬이 되어, 이전 선택이 이후 전투 스타일을 바꿈
7. 이중인격 손님(DAY 6)이 주인공의 정체를 암시하는 복선 역할
8. 마지막엔 남에게 썼던 방식을 자기 자신에게 적용, 안식/용기 파편 비율로 망각/노멀/용기 엔딩 분기
9. 초반부터 가진 네 개의 파편이 주인공의 과거와 연결되며 후반부에 의미가 뒤집힘
