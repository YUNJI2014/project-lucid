# 13호 악몽 여관

> 낮에는 손님을 관찰하고, 밤에는 그들의 악몽 속으로 들어간다.
> 기억을 지우면 악몽은 약해진다.
> 하지만 기억이 사라진 사람이 과연 치료된 사람일까?

**여관 운영 + 3D 악몽 탐색/실시간 전투 + 스토리 어드벤처** — Unity 1인용 게임.

| | |
|---|---|
| 플레이 인원 | 1인 |
| 진행 기간 | 게임 내 30일 |
| 그래픽 | 현실 **2D 도트** / 악몽 **3D** |
| 리포지토리명 | `project-lucid` (가제 시절 이름, 타이틀 확정으로 rename 예정) |

---

## 무슨 게임인가

플레이어는 **몽식증**(감정이 악몽으로 구체화되는 증상) 환자들이 머무는 오래된 여관의 새 주인이다.

- **낮 (2D)** — 손님을 받고 여관을 운영하며 손님의 행동을 관찰한다.
- **밤 (3D)** — 손님의 악몽 속으로 들어가 탐색하고, 단서와 무기를 모아 실시간 전투를 치른다.

적의 체력을 깎는 게 전부가 아니다. 악몽의 **공격 패턴은 각각 특정 기억과 연결**되어 있어서,
그 기억을 삭제하면 패턴 자체가 사라진다.

**단, 삭제한 기억은 현실의 손님에게도 반영된다.** 전투를 쉽게 만드는 선택이 좋은 치료라는 보장은 없다.

## 핵심 루프

### 일반 손님 (그날 밤 해결, 주 수입원)
```
체크인 → 2D 여관 운영 → 밤 → 3D 악몽 → 짧은 실시간 전투 → 보상 → 퇴실
```

### 특성 손님 (며칠에 걸친 본편)
```
체크인 → 며칠간 관찰 → 3D 1인칭 악몽 탐색(전투 X)
       → 단서·무기 획득 → 스킬셋 구성
       → 기억 조각 접촉 → 전용 실시간 전투
       → 기억 삭제 여부 선택 → 현실 결과 확인
```

낮과 탐색에서 얻은 정보가 그대로 전투 공략법이 된다.

### 메인 스토리 (30일)
```
남의 악몽을 치료 → 탐색맵 곳곳에서 자신의 과거 단서 발견
→ 자신도 과거 이 여관의 환자였음을 확인
→ 연인의 죽음과 자기혐오로 분리된 두 자아를 확인
→ 마지막으로 자신의 기억을 마주함
```

엔딩은 **무엇을 해결했는가**가 아니라 **무엇을 기억한 채 살아갈 것인가**를 보여준다.
완전한 해피엔딩은 없다.

## 주요 특성 손님

| 손님 | 핵심 테마 | 기믹 |
|---|---|---|
| 치매 환자 | 기억 소실 / 정보의 불균형 | 공간 구조가 계속 바뀌고, 벌레가 플레이어의 스킬·정보를 지운다. **캐릭터는 잊지만 플레이어는 기억한다**는 격차가 공략 포인트 |
| 퇴역 기사 | 전쟁 트라우마 / 환청 | 지키지 못한 병사들의 폭언이 문장 형태로 공간에 떠올라 직접 피해를 준다. 정보가 있으면 거짓 기억을 구분·약화 가능 |
| PTSD 환자 | 사건의 반복 / 트리거 | 사이렌·유리 깨지는 소리 등 트리거마다 환각이 강화된다. 탐색에서 트리거를 특정하면 사전 대비 가능 |

## 차별점

1. 2D 현실과 3D 악몽의 강한 대비 — **악몽이 현실보다 더 생생하다**는 감각 자체가 후반 복선
2. 특성 손님을 며칠간 관찰한 뒤 전투하는 구조
3. 전투 전 3D 탐색으로 단서·무기를 모아 스킬셋을 구성
4. **기억을 삭제하면 적의 공격 패턴 자체가 삭제**되는 전투 시스템
5. 그 삭제가 현실 속 손님에게도 반영되는 대가 구조
6. 탐색맵에 아주 약하게 숨겨진 플레이어 본인의 과거 복선
7. 마지막엔 남의 기억이 아니라 자신의 기억을 선택하게 되는 구조
