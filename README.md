# 13호 악몽 여관

> 낮에는 손님을 관찰하고, 밤에는 그들의 악몽 속으로 들어간다.
> 기억을 지우면 악몽은 약해진다.
> 하지만 기억이 사라진 사람이 과연 치료된 사람일까?

**여관 운영 + 단서 탐색 + 2D 턴제 전투 + 스토리 어드벤처** — Unity 1인용 게임.

| | |
|---|---|
| 플레이 인원 | 1인 |
| 진행 기간 | 게임 내 30일 |
| 그래픽 | 전체 **2D** |
| 리포지토리명 | `project-lucid` (가제 시절 이름, 타이틀 확정으로 rename 예정) |

---

## 무슨 게임인가

플레이어는 **몽식증**(감정이 악몽으로 구체화되는 증상) 환자들이 머무는 오래된 여관의 새 주인이다.

- **낮** — 손님을 체크인시키고 객실을 청소하며, 제한된 횟수 안에서 방 안의 단서를 조사한다.
- **밤** — 손님의 악몽 속으로 들어가, 낮에 모은 단서를 근거로 2D 턴제 전투를 치른다.

적의 체력을 깎는 게 전부가 아니다. 악몽의 **공격 패턴은 각각 특정 기억과 연결**되어 있어서,
그 기억을 삭제하면 패턴 자체가 사라진다. 삭제 대신, 단서를 충분히 모았다면 기억을 지우지 않고
받아들이게 만드는 **정화**를 선택할 수도 있다.

**단, 삭제한 기억은 현실의 손님에게도 반영된다.** 전투를 쉽게 만드는 선택이 좋은 치료라는 보장은 없다.

## 핵심 루프

```
손님 체크인
→ 객실 청소
→ 제한된 횟수로 단서 탐색
→ 밤에 악몽 진입
→ 단서를 이용한 2D 턴제 전투
→ 기억 삭제 또는 정화
→ 안식/용기 파편 획득
→ 스킬 장착
→ 다음 손님
```

낮에 얻은 정보가 그대로 밤 전투의 공략법이 된다. 기억 삭제는 **안식 파편**(강한 공격 위주),
정화는 **용기 파편**(보호·회복·정보 위주)을 준다. 파편으로 짠 스킬 빌드는 최종 엔딩에도 영향을 준다.

### 메인 스토리 (30일)
```
남의 악몽을 치료 → 탐색 중 곳곳에서 자신의 과거 단서 발견
→ 자신도 과거 이 여관의 환자였음을 확인
→ 연인의 죽음과 자기혐오로 분리된 두 자아를 확인
→ 마지막으로 자신의 기억을 마주함
```

엔딩은 **무엇을 해결했는가**가 아니라 **무엇을 기억한 채 살아갈 것인가**를 보여준다.
완전한 해피엔딩은 없다.

## 주요 손님

| 손님 | 핵심 테마 | 기믹 |
|---|---|---|
| 치매 환자 | 기억 소실 / 정보의 불균형 | 낮에 조사한 방 구조가 밤마다 바뀐다. 기억을 갉아먹는 존재가 스킬·정보를 지운다. **캐릭터는 잊지만 플레이어는 기억한다**는 격차가 공략 포인트 |
| 퇴역 기사 | 전쟁 트라우마 / 환청 | 지키지 못한 병사들의 폭언이 문장 형태로 공간에 떠올라 직접 피해를 준다. 군번줄·편지 같은 단서로 거짓 기억을 구분·약화 가능 |
| PTSD 환자 | 사건의 반복 / 트리거 | 사이렌·유리 깨지는 소리 등 트리거마다 환각이 강화된다. 낮에 트리거를 특정하면 사전 대비 가능 |

---

## 차별점

1. 낮의 제한된 단서 조사 → 밤의 2D 턴제 전투로 이어지는 통합 루프
2. 여관 파트가 별도 경영 게임으로 튀지 않고, 청소가 탐색의 명분이 되는 구조
3. **기억 삭제**(패턴 제거, 대가 있음)와 **정화**(단서 기반, 안정적) 두 갈래 공략법
4. 그 선택이 현실 속 손님에게도 반영되는 대가 구조
5. 안식/용기 파편 기반 스킬 빌드가 최종 엔딩에도 영향
6. 탐색 중 매우 약하게 숨겨진 플레이어 본인의 과거 복선
7. 마지막엔 남의 기억이 아니라 자신의 기억을 선택하게 되는 구조
