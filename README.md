# 13호의 여관

> 고통을 지워 안식을 얻을 것인가, 아니면 기억한 채 살아갈 용기를 가질 것인가?

**3D 스토리 어드벤처 + 퍼즐/탐색 + 실시간 액션 전투** — Unity 1인용 게임.

## 무슨 게임인가

플레이어는 7일 동안 여관에 찾아오는 손님들을 상대한다.
손님이 방에 들어가면 평범했던 객실은 손님의 기억과 트라우마에 영향을 받아 **3D 악몽 영역**으로 변화한다.

플레이어는 그 영역에 직접 들어가 퍼즐·퀴즈·미로·방탈출형 기믹을 풀며 손님의 과거에 대한 단서와 증거물을 모은다.
영역의 끝에서 손님과 직접 대면해 **3D 실시간 액션 전투**를 치르고, 기억을 삭제하거나 단서를 활용해 정화한다.

기억 삭제는 **안식 파편**, 정화는 **용기 파편**을 준다. 파편은 이후 전투 스킬이 되어, 제한된 슬롯에 원하는 만큼 장착해 전투 빌드를 구성한다.

---

## 핵심 루프

```
손님 등장
→ 손님이 객실에 입실
→ 객실이 악몽 영역으로 변화
→ 플레이어가 영역 진입
→ 퍼즐·미로·방탈출·퀴즈 진행
→ 단서 및 증거물 획득
→ 손님과 최종 대면
→ 실시간 전투
→ 기억 삭제 또는 정화
→ 안식/용기 파편 획득
→ 스킬 슬롯 장착
→ 다음 날
```

하루에 한 명씩, 총 7일 동안 진행한다.

## 7일 구성

| 구분 | Day | 손님 |
|---|---|---|
| 간단 손님 (튜토리얼) | DAY 1 | 잔소리 공포 |
| | DAY 2 | 물 공포 |
| | DAY 3 | 시선 공포증 |
| 핵심 손님 (기믹 심화) | DAY 4 | 치매 |
| | DAY 5 | PTSD |
| | DAY 6 | 이중인격 |
| 최종 | DAY 7 | 주인공 자신 |

마지막 날, 플레이어는 13호실에서 **자기 자신의 트라우마**와 마주한다. 선택에 따라 망각/노멀/용기 세 엔딩으로 갈린다.

---

## 차별점

1. 손님의 객실이 트라우마를 기반으로 한 3D 악몽 영역으로 변화
2. 손님마다 다른 퍼즐·미로·방탈출형 기믹
3. 탐색에서 얻은 단서가 실시간 전투에 직접 사용됨 (공격 패턴 공개, 증거 제시, 정화 조건)
4. 기억 삭제 시 해당 기억과 연결된 공격 패턴 자체가 제거됨
5. 기억 삭제 → 강력한 **안식 파편**, 정화 → 안정적인 **용기 파편**, 둘 다 실제 전투 스킬로 사용
6. 간단 손님 3명으로 시스템을 학습하고 핵심 손님 3명에서 기믹을 심화
7. 이중인격 손님(DAY 6)이 주인공의 정체를 암시하는 복선 역할
8. 마지막엔 남에게 썼던 시스템을 자기 자신에게 적용, 플레이에 따라 망각/노멀/용기 엔딩 분기
